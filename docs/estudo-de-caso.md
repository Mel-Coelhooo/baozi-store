# Estudo de Caso – Baozi Store

A **Baozi Store** é uma pequena loja que vende **pão chinês**.
Para melhorar a organização do negócio, foi criado um sistema simples para controlar clientes, produtos e pedidos.

Uma cliente chamada **Melissa5598704** realizou seu cadastro no sistema em 22/11/2026.

O produto vendido pela loja chama-se **Baozi de Porco** e é vendido por unidade, ao preço de **R$ 6,50**, estando disponível em estoque.

Em um determinado momento, a cliente realizou um pedido de **10 unidades** do produto.

O sistema registra a cliente, o produto comprado e a quantidade solicitada, facilitando o controle da loja.
